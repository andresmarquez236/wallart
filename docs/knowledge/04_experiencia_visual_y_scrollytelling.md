# Experiencia visual recomendada

La web debe tener una estética de galería contemporánea digital, no de plantilla genérica.

**Dirección artística sugerida:**
- Fondo oscuro elegante o fondo neutro editorial.
- Tipografía grande, limpia y sofisticada.
- Fotografías de cuadros en espacios reales.
- Animaciones suaves, no saturadas.
- Mucho espacio negativo.
- Secciones inmersivas y transiciones tipo galería.
- Videos cortos de antes/después.
- Mockups hiperrealistas.

# Scrollytelling recomendado para la Home

La Home narra una historia a medida que el usuario hace scroll:

1. **Sección 1: Impacto:** Hero cinematográfico. Paredes cambiando. "Tu pared no está vacía. Está esperando una historia."
2. **Sección 2: Transformación:** Scroll con antes (vacío) y después (con cuadro, luces, atmósfera).
3. **Sección 3: Dos caminos:** "Elige una obra lista" o "Crea una obra con tu historia".
4. **Sección 4: Personalización:** Animación del proceso (subir imagen -> estilo -> tamaño -> vista previa -> recibir).
5. **Sección 5: Colecciones:** Presentadas como salas de museo (Abstracto, Minimalista, etc.).
6. **Sección 6: Prueba social:** Fotos reales, empaques, reseñas.
7. **Sección 7: Garantía y confianza:** Envíos, pagos, asesoría, calidad.
8. **Sección 8: Cierre emocional:** "Haz que tu espacio hable por ti." + CTA final.
